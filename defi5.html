Défi 5

✏️ Tracer des segments

🎯 Ta mission

Trace des segments de longueurs précises en utilisant les outils GeoGebra.

Tu dois être exact ! Vérifie tes mesures après avoir tracé.

📋 Étapes à suivre :

  1. Clique sur l'outil "Segment de longueur donnée"
  2. Clique sur un point de départ
  3. Entre la longueur demandée
  4. Vérifie avec l'outil "Distance"

🎯 Segments à tracer :

1. Un segment [AB] de 5 cm

2. Un segment [CD] de 3,5 cm

3. Un segment [EF] de 7,2 cm

4. Un segment [GH] de 4,8 cm

💡 Astuce

Utilise la virgule (,) et non le point pour les décimaux dans GeoGebra !

🔧 Activité GeoGebra

C'est un GeoGebra vierge - à toi de construire !

✅ Validation

Tu as fini ? Appelle ton professeur pour valider ton travail !

Le professeur vérifiera :

  • Que tous les segments sont présents
  • Que les longueurs sont exactes
  • Que les segments sont bien nommés
🙋 Lève la main pour appeler le professeur !

Après validation, ton professeur te donnera le code pour la porte suivante 🔐
