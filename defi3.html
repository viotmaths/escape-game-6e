🔄 Convertir les unités

🎯 Ta mission

Utilise le tableau de conversion pour transformer les longueurs dans les unités demandées.

Rappelle-toi : km → hm → dam → m → dm → cm → mm

📋 Tableau de conversion :

km hm dam m dm cm mm

💡 Astuces

• Pour aller vers la droite (plus petit) → ×10
• Pour aller vers la gauche (plus grand) → ÷10

🔧 Activité GeoGebra

Si l'activité ne charge pas, assure-toi que le fichier niveau3.ggb est bien dans le dossier.
